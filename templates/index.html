How to use

  1. Create a Gemini API key at Google AI Studio.
  2. Build your resume JSON. Ask Gemini to create a JSON profile from your resume, then paste it into the Resume Profile tab. Make sure it includes the expected fields (full_name, email, phone, skills, etc.).
  3. Set your API key. Go to the Env tab and add GEMINI_API_KEY=your_key.
  4. Fill the Config. In the Config tab set your role, location, resume path, applicant cap, and LLM provider (gemini or local).
  5. Log in to LinkedIn. Click Start Login. Sign in with your LinkedIn username and password in the browser. When done, return and click Login Successful.
  6. Start the search. Click Start Search to run the application pipeline.
